#### 1️⃣ Shopify Order → Instant Digital Delivery
- **Real-time webhook trigger** — fires the second an order is placed
- **Smart filtering** — only processes digital products (`fulfillment_service: digital` or `product_type: Digital`)
- **Auto-fetches from Google Drive** — organized by product handle (e.g., `my-template.zip`)
- **Sends branded email with attachment** — HTML + plain text, your branding
- **Audit trail** — moves file to "Delivered" folder automatically
- **Error handling & logging** built in

#### 2️⃣ Etsy Order → Digital Delivery (Works with Etsy's Native Files)
- **Polls Etsy API every 10 minutes** for new paid orders
- **Detects digital transactions automatically** — `is_digital: true` or `digital_file_id` present
- **Fetches download URL directly from Etsy** — no Google Drive needed!
- **Sends branded email with secure download link**
- **Success/failure logging** included

#### 3️⃣ Shopify + Etsy → Unified HubSpot CRM + Smart Review Requests
- **One CRM view for BOTH platforms** — aggregates orders into single flow
- **Creates/updates HubSpot contacts** — unified customer profiles
- **Creates deals** — Closed Won, amount = order total
- **Adds timeline notes** — full order details on contact record
- **Smart tags**: Repeat Customer • High-Value ($100+) • Digital Buyer • Physical Buyer
- **Conditional review requests** — ONLY emails repeat buyers of PHYSICAL products (digital buyers already got instant delivery — don't annoy them!)
