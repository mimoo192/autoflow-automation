## Product Description (Gumroad long-form)

### The Problem
You sell digital products on Shopify and/or Etsy. Every time an order comes in, you manually:
- Check if it's a digital product
- Find the right file in your Google Drive
- Email the customer with a download link (or attachment)
- Update your CRM/spreadsheet with the customer info
- Maybe send a review request later

**That's 15–30 minutes per order. At 20 orders/week, that's 10+ hours of repetitive work.**

### The Solution
**AutoFlow** is a pack of 3 production-ready n8n workflow templates that handle this entire loop automatically:

---

#### 📦 Template 1: Shopify Order → Digital Delivery
**Webhook-triggered. Real-time. Zero delay.**
- Triggers instantly when a Shopify order is placed
- Smart filtering: only processes digital products (by `fulfillment_service: digital` or `product_type: Digital`)
- Fetches the correct `.zip` file from your Google Drive (organized by product handle)
- Sends a beautiful, branded email with the file attached via Gmail
- Moves the file to a "Delivered" folder for audit tracking
- Complete error handling + success logging

> **Perfect for:** Notion templates, ebooks, presets, printables, software licenses, courses with downloadable assets

---

#### 🛍️ Template 2: Etsy Order → Digital Delivery
**API polling. Works with Etsy's native digital files.**
- Polls Etsy API every 10 minutes for new paid receipts
- Detects digital transactions automatically (`is_digital: true` or `digital_file_id` present)
- Fetches the download URL directly from Etsy's API (no Google Drive needed!)
- Sends a branded email with the secure download link
- Success/failure logging included

> **Perfect for:** Etsy-native digital listings, printables, patterns, digital planners

---

#### 🔄 Template 3: Shopify + Etsy → Unified HubSpot CRM + Smart Review Requests
**One CRM view for both platforms. Intelligent automation.**
- Aggregates new orders from BOTH Shopify (webhook) and Etsy (API) into one flow
- Creates/updates HubSpot contacts with unified customer profiles
- Creates deals for each order (stage: Closed Won, amount = order total)
- Adds order notes to the contact timeline automatically
- **Smart tagging**: repeat customer, high-value ($100+), digital buyer vs physical buyer
- **Conditional review requests**: Only emails repeat buyers of PHYSICAL products (digital buyers already got instant delivery — don't annoy them!)
- Complete audit trail

> **Perfect for:** Sellers on both platforms who want one customer view + automated social proof
