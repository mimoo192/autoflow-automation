3 Workflows That Run Your Digital Product Business

Each template is a complete, import-ready n8n workflow JSON file. Configure your credentials once, customize the placeholders, and activate.

Shopify Order → Digital Delivery

Instantly deliver digital files when a Shopify order comes in. Webhook-triggered, filters digital products, fetches from Google Drive, emails the customer with attachment.

  • Shopify webhook trigger (real-time)
  • Filters by fulfillment_service or product_type
  • Fetches .zip from Google Drive by product handle
  • Sends branded email with attachment via Gmail
  • Moves file to "Delivered" folder for tracking
  • Error handling & success logging

Requires: Shopify store, Google Drive, Gmail

Etsy Order → Digital Delivery

Poll Etsy for new paid orders, detect digital transactions, fetch the file URL from Etsy's API, and email the download link automatically.

  • Etsy API polling (every 10 minutes)
  • Detects is_digital & digital_file_id
  • Fetches download URL from Etsy directly
  • Sends branded email with download link
  • Works with Etsy's native digital delivery
  • Error handling & success logging

Requires: Etsy Developer App (API key + OAuth), Gmail

Shopify + Etsy → Unified CRM + Reviews

Aggregate orders from BOTH platforms into HubSpot. Creates contacts, deals, and timeline notes. Smart tags: repeat buyers, high-value, digital vs physical. Auto-requests reviews from repeat physical buyers only.

  • Unifies Shopify webhook + Etsy API orders
  • Creates/updates HubSpot contacts & deals
  • Adds order notes to contact timeline
  • Smart tags: repeat, high-value ($100+), digital/physical
  • Conditional review requests (repeat physical buyers only)
  • Complete audit logging

Requires: Shopify, Etsy Developer App, HubSpot, Gmail
